# V9.2 test evidence

> **Historical document.** Written for an earlier version, before the QIE mainnet deployment of 23 Nov 2026. Statements about what has or has not been deployed, which wallets to create and test counts describe that time. Current state: [`FINAL_RELEASE_READINESS.md`](FINAL_RELEASE_READINESS.md).

Everything below was executed on 2026-11-20 by `bash scripts/run-evidence.sh`, from a clean copy of this folder with no `node_modules`, `artifacts` or `cache`. The raw output of every step is in [`evidence/`](evidence/); nothing here is carried over from v9 or v9.1.

## Environment

- Linux x86_64, Node.js v22.23.5, npm 10.9.9, registry `https://registry.npmjs.org/` (reachable; installs used the lockfiles via `npm ci`)
- Solidity 0.8.39, EVM target paris, Hardhat 2 (versions pinned by `package-lock.json`)

**The 3 pending tests** are `SavingsCircle.exhaustive.test.js` (7,776 default patterns × 3 cover levels, about 45 minutes). They are skipped unless `EXHAUSTIVE=1` and **were not run for v9.2**.

**What the 107 tests include:** the scenario, attack, v6 and invariant suites (150 random default patterns, now alternating both collateral modes, with ledgers checked against the token balance after every call); `SavingsCircle.v92.test.js` (10 tests); and the parity suite (30 tests: 14 named scenarios × 2 modes, a precision test of 12 cases from 1 base unit to the maximum contribution, and 160 random scenarios). Each parity test compares the full contract state after every step.

**Slither note:** the step's exit code is 0 because the script records Slither's own exit status (255, "findings reported") in the log rather than stopping. The 11 results:
- Divide-before-multiply: `finalize` and `_shareEqually` compute `each = amount / n; rem = amount − each × n`, which is exact remainder arithmetic.
- Strict equality: zero checks on internal ledgers (`_withdraw`, `finalize`, `risk`), not on token balances.
- Calls inside a loop: `CircleFactory.recordCircle`, at most 12 calls, only on circles the factory itself created.
- Timestamp comparisons: the round schedule, by design.

None involve the v9.2 changes. No linter (ESLint or solhint) is configured in this project, so none was run.

## Not verified

- The exhaustive suite (see above).
- Anything on QIE mainnet: the real QUSDC token, the QIE Wallet and the QIE RPC. Nothing was deployed and no funds were moved.
- The app in a real wallet. The screens were checked in a headless browser against a local chain (create screen, cover gating with a 50%-minimum factory, a factory address without a contract); signing transactions in the UI was not exercised.
- Known cosmetic issue: on local runs, `demo-mainnet.js` still prints a mainnet explorer link at the end.
